# Security model

HermesNag is single-user personal software. Its boundaries:

- **The API never leaves localhost.** FastAPI binds `127.0.0.1` only. Remote
  access is via an SSH local port-forward (Mac) or `tailscale serve`
  (phone) — both authenticated transports you already control.
- **Bearer token on every route except `/health`.** Generated by
  `install.sh`, stored in `.env` (0600) on the server and the macOS Keychain
  on the client. Constant-time comparison. The QR handoff carries the token
  in a URL *fragment*, which browsers do not transmit.
- **Nothing is ever deleted.** `dropped` is a status; the event table is
  append-only. Undo is recorded, not erased.
- **Agent boundaries.** An integrated agent gets scoped tools through a local
  MCP server; it cannot mint `must`-priority (screen-takeover tier) tasks
  from automation paths, and everything it creates is attributed and traceable.

Report issues via GitHub issues. There is no bug-bounty; it's a desk lamp,
not a bank.
