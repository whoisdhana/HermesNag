# HermesNag 🔔

An agent-powered task, habit and reminder system for people who live at a
desk. A glanceable macOS desktop widget + iPhone web widget, backed by a tiny
self-hosted server, with an optional AI agent that creates tasks from your
email, writes the reminder copy, and coaches your streaks.

**Philosophy:** passive by default. It sits on your desktop; you glance at
it. Popups are opt-in, escalate only by your rules, never fire while you're
presenting or watching full-screen video, and a water reminder can never
seize your screen.

```
┌─ your VPS ─────────────────────────────────────────────┐
│  agent (optional) ──MCP──▶ task service (FastAPI+SQLite│
│  cron: briefs, email→tasks,     127.0.0.1 only)        │
│        nag copy, backups                               │
└──────────┬──────────────────────────────┬──────────────┘
     ssh -L tunnel                 tailscale serve
           ▼                              ▼
     macOS widget                  iPhone web widget
     (SwiftPM, no Xcode)           + Scriptable + Siri
```

## Features

- **Tasks** — natural language ("pay bill friday 6pm #home urgent"),
  recurring ("van fee every month 5th" → rolls forward on completion),
  FORCE/PENDING/COMPLETED sections with strikethrough, undo, snooze
- **Habits** — presence-aware office health nudges (stand up only fires if
  you've actually been sitting), active-hours windows, gentle escalation
- **Capture from anywhere** — ⌃⌥Space quick-add, phone add bar, Siri
  dictation, or the agent watching your email
- **Score** — points/levels/achievements replayed from an append-only event
  ledger; no penalties ever, undo is neutral bookkeeping
- **Escalation ladder (opt-in)** — playful panel → annoyed panel →
  full-screen takeover, with hard safety valves: never while presenting or
  screen-locked, rate-limited, kill switch, ⌃⌥⌘Esc panic key
- **Offline-first** — cached snapshot + durable action queue; SSE push with
  polling fallback; everything reconciles when the tunnel returns

## Quickstart

Three tiers — each works without the next:

1. **Server + Mac widget** — `docs/DEPLOYMENT.md`. Static nag lines included;
   no agent required.
2. **+ iPhone** — Tailscale + one `tailscale serve` line; scan the QR from
   Settings. Home-screen widget via Scriptable; voice add via Shortcuts.
3. **+ Agent** — any MCP-capable agent gets 10 tools (create/list/complete
   tasks, manage habits, write nag copy, read the scorecard) plus a skill
   file defining taste: when a habit vs a task, why auto-created work is
   never takeover-tier, how to coach streaks without guilt.

## Configuration

| Where | Key | Meaning |
|---|---|---|
| server `.env` | `HERMESNAG_TOKEN` | bearer token (generated by install.sh) |
| server `.env` | `HERMESNAG_DISPLAY_TZ` | IANA zone for day boundaries (storage is UTC) |
| Mac defaults | `sshHost` | `~/.ssh/config` alias of your server (Settings) |
| Mac defaults | `phoneBaseURL` | tailnet HTTPS base for the QR (Settings) |
| Mac defaults | `nagsEnabled` | popup ladder on/off (default off) |
| Mac defaults | `disableTakeover` | kill switch for L3 |
| Mac defaults | `widgetLayer` | desktop / normal / floating |

## Hard-won gotchas (read before hacking)

- Swift's `AsyncLineSequence` swallows blank lines — the SSE parser emits on
  `data:` frames, never on blank-line terminators.
- FastAPI sync endpoints run in a threadpool: broadcasting from them requires
  `call_soon_threadsafe`, or every event silently drops.
- A borderless non-activating `NSPanel` can still become key and swallow a
  Return meant for another app — completing tasks nobody completed.
- `desktopIconWindow` level renders *behind the wallpaper*: AppKit reports a
  healthy frame while the window server composites nothing.
- SQLite + WAL returns naive datetimes; a TypeDecorator re-attaches UTC, and
  naive input is rejected with a 400 — never guessed.
